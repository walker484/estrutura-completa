Curso Walker CRM

Nesta página você vai aprender a criar a estrutura inicial do Walker CRM usando Terminal e Node.js.

Primeiro criamos as pastas e arquivos. Depois colocamos o código dentro de cada arquivo.

Curso de Node.js

Esta etapa é importante para entender a tecnologia que estamos usando no servidor do Walker CRM.

O curso aborda fundamentos do Node.js, módulos, REST API, MongoDB, upload de arquivos e outros assuntos.

3. server.js

walker-crm/server.js

É o servidor principal do Walker CRM. 

const express = require("express");
const path = require("path");

const app = express();

const PORT = 3000;

app.use(express.json());

app.use(
  express.static(
    path.join(__dirname, "public")
  )
);

app.get("/api/status", (req, res) => {

  res.json({
    sistema: "Walker CRM",
    status: "online"
  });

});

app.listen(PORT, () => {

  console.log(
    `Walker CRM rodando na porta ${PORT}`
  );

});

9. services/mensagens.js

walker-crm/services/mensagens.js

Organiza as mensagens recebidas e enviadas. 

function criarMensagem(
  clienteId,
  texto,
  origem
) {

  return {

    id: Date.now(),

    clienteId: clienteId,

    texto: texto,

    origem: origem,

    data:
      new Date().toISOString()

  };

}

module.exports = {
  criarMensagem
};

10. services/ia.js

walker-crm/services/ia.js

11. services/resposta.js

walker-crm/services/resposta.js

Prepara a resposta depois da análise da mensagem. 

function prepararResposta(
  analise
) {

  if (
    analise.intencao ===
    "atendimento"
  ) {

    return analise.sugestao;

  }

  return "Vou encaminhar seu atendimento.";

}

module.exports = {
  prepararResposta
};

12. package.json

O comando npm init -y cria esse arquivo automaticamente.

Não é necessário criar manualmente node_modules nem package-lock.json.
